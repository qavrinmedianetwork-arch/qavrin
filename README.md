# QAVRIN V1 REAL

This is the new mobile-first QAVRIN frontend milestone.

Core flow: account -> login -> write -> publish -> like -> comment -> save -> profile.

The current build stores demo data in the browser so the interface can be tested immediately. For real multi-user launch, connect these same screens to Supabase Auth/PostgreSQL/RLS.

Do not use browser-local passwords for production.
